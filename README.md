- **Why the website matters:** parents need to recognise the service, understand its relevance to a child's learning needs and know how to approach the provider.

## The problem

Finding suitable tuition can involve more than searching for a teacher's name. Parents typically need to consider a child's school level, subject requirements, location, learning needs and scheduling preferences. Tutors, meanwhile, need a way to make their availability and teaching specialisms discoverable.

For a local service, the communication challenge is to explain **who can request tuition, what type of support the business offers and why a family should make an enquiry** without making the experience needlessly complicated.

The portfolio confirms Ghar Shiksha's tutoring proposition, but it does not provide an independently documented audit of any previous website or its conversion problems.

## How Tech Conversion presents the project

The points below describe the purpose and editorial direction supported by the public project listing. They do not claim to document the complete internal design or development process.

1. **Make the audience immediately clear.** The project is positioned for Bhopal families seeking home-learning support, rather than a broad, unspecified education audience.
2. **Explain the tutor-connection proposition.** The central message is about helping parents and students connect with tutors for more personalised learning.
3. **Keep local relevance visible.** Identifying Bhopal matters to families evaluating practical, location-dependent home tuition.
4. **Build trust without overstating proof.** The portfolio uses tutor verification as a selling point. Any detailed claims about screening, checks or qualifications should be published only with supporting evidence.
5. **Create a clear path towards an enquiry.** A home-tuition website should make the next action apparent. Actual enquiry-form behaviour and submission handling have not been independently tested for this record.
6. **Account for both sides of the service.** Parents and students need an understandable way to request learning support; tutors need accurate information about how to participate if recruitment is offered.

## Relevant website quality standards

These are appropriate review criteria, not claims that this particular project has passed an audit or holds certifications:

- [Core Web Vitals](https://web.dev/articles/vitals): assess loading, interaction responsiveness and layout stability on typical phones.
- [WCAG 2.2, Level AA](https://www.w3.org/TR/WCAG22/): assess text contrast, keyboard support, focus visibility, accessible forms and alternative text.
- [Google Search Essentials](https://developers.google.com/search/docs/essentials): review useful pages, crawlability and appropriate local-search presentation.
- [Schema.org](https://schema.org/): consider accurate organisation, service and breadcrumb markup where relevant and implemented.
- [Digital Personal Data Protection framework](https://www.meity.gov.in/data-protection-framework): review notices, data collection and permission for parent, tutor and student information as applicable.

**Child and family data:** any handling of children's personal information needs particular care. This README does not claim that a specific consent mechanism, safeguard or regulatory assessment has been implemented.
